## Prompt 1 — Xây dựng CSS Grid từ cấu trúc HTML cũ
Dựa trên file HTML Portfolio của bài trước, giữ nguyên cấu trúc nội dung chính và bổ sung CSS để tạo bố cục bằng CSS Grid. Chia trang thành Sidebar và Main Content với `grid-template-columns: 1fr 3fr`. Header và Footer phải trải dài toàn bộ chiều rộng bằng `grid-column: 1 / -1`.

## Prompt 2 — Flexbox cho kỹ năng và navigation
Sử dụng Flexbox cho thanh điều hướng và danh sách kỹ năng. Danh sách kỹ năng dùng `display: flex`, `flex-wrap: wrap` và `gap` để các skill tag tự động xuống dòng khi không đủ không gian.

## Prompt 3 — Kiểm tra lỗi bố cục
Check this CSS Grid code for any overlap issues and fix the responsive column sizing.

## Prompt 4 — Responsive
Tối ưu CSS Grid và Flexbox để Portfolio hiển thị tốt trên desktop, tablet và mobile. Khi màn hình nhỏ, chuyển bố cục hai cột thành một cột, không để nội dung bị tràn hoặc chồng lấn.
